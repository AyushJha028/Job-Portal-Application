# Job Portal (Django)

A Django-based Job Portal application that allows users to register, browse jobs, and apply online.  
This project demonstrates full-stack development with Django, including authentication, job listings, and application management.

---

## 🚀 Features
- User registration and login (Django auth)
- Job listings with categories
- Apply for jobs directly through the portal
- Admin dashboard for managing jobs and applications
- Modular apps: `accounts`, `jobs`, `jobportal`

---

## 🛠 Tech Stack
- **Backend:** Django, Python
- **Database:** SQLite (development), MySQL (production-ready)
- **Frontend:** Django templates, Bootstrap
- **Environment:** Virtualenv

---
